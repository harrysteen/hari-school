# HARI E-TECHNO SCHOOL — Official Portal & Website

A high-performance single-page web application and student portal for **HARI E-TECHNO SCHOOL (Rajanagaram • Jagannadhapuram • Andhra Pradesh)**. Built with **Next.js 15 App Router**, **React 19**, **TypeScript**, and customized Vanilla CSS.

---

## 🌟 Key Features

- **Dynamic 100vh Hero Section**: Custom animations with organic arched visual cards, Indian student photography, and 3D floating stickers.
- **Full Responsive Navigation**: Adaptive navbar with animated mobile drawer (`<= 1220px`) ensuring perfect display across 4K, laptops, tablets, and phones.
- **🪔 Dasara Holidays Special Classes Portal (`/dasara-camp`)**:
  - Roll number & student admission verification gate.
  - Live Zoom & Google Meet video room links with live pulse badges.
  - Downloadable holiday practice sheets & worksheets (Day 1 to Day 5).
  - 24/7 Teacher WhatsApp Doubt Desk.
- **🚀 Grand Exam 2026 Portal**: Integration links for SPE practice, April 30 mock exams, and analytics.
- **Principal's Desk Section**: Executive portrait, leadership quote, and direct interaction booking.
- **Interactive Admissions Enquiry Modal**: Multi-step enquiry form with instant feedback.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3005](http://localhost:3005) with your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
